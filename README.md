# Amazon Fine Food Review Analytics

## Overview

This project analyzes customer reviews from the Amazon Fine Food Reviews dataset using Natural Language Processing (NLP). It compares lexicon-based and transformer-based sentiment analysis approaches while identifying product aspects that drive customer satisfaction and dissatisfaction.

## Features

- Exploratory Data Analysis (EDA)
- Text preprocessing
- Sentiment analysis using VADER
- Sentiment analysis using RoBERTa
- Hugging Face sentiment pipeline
- Model performance comparison
- Aspect-based review analysis
- Business insights and recommendations

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- NLTK
- VADER
- Hugging Face Transformers
- RoBERTa

## Key Outcomes

- Compared traditional and transformer-based sentiment models.
- Identified customer sentiment across key product aspects.
- Highlighted major customer pain points and positive product attributes.
- Generated business recommendations based on customer feedback.
